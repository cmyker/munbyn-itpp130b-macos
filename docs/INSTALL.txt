MUNBYN ITPP130B Bridge — experimental alpha

This independent application is not affiliated with MUNBYN.
Supported model: ITPP130B only. Other MUNBYN models are not validated.
This download is for Apple Silicon Macs. Minimum deployment target is
macOS 13; runtime and printer testing currently cover macOS 15.7.9 only.

INSTALL
1. Quit any existing MUNBYN ITPP130B Bridge before replacing its app.
2. Drag MUNBYN ITPP130B Bridge.app to Applications. Eject the disk image.
   ZIP users: extract the app and move it to Applications instead.
3. Open the installed application. This alpha is ad-hoc signed and not
   notarized. If macOS blocks it, and you trust the downloaded release,
   use System Settings > Privacy & Security > Open Anyway after attempting
   to open it. Do not disable Gatekeeper or SIP globally. A managed Mac
   may prevent approval. See Apple's instructions:
   https://support.apple.com/en-us/102445
4. Click the printer icon in the menu bar and open Settings > Printer > Select Printer.
   Allow Bluetooth permission; explicitly select your physical ITPP130B.
5. In Settings > Printer, choose Repair / Install Printer Queue. Approve the administrator prompt
   if required. Only the separate Bluetooth queue is created; existing USB
   and default printer settings are not changed by the installer.
6. Load matching stock and use Settings > Printer > Print Test Label once. Inspect the
   physical output before routine printing. Dry Run is available for
   synthetic software checks and creates sensitive local captures.

PRINT
Keep the bridge running in your logged-in session. Open a label-sized PDF
in Chrome or Preview and select MUNBYN ITPP130B (Bluetooth) in Cmd+P. Choose
the matching 100 x 150 mm or 4 x 6 inch media. Chrome may require See more.
No compilation, Terminal command, USB cable or separate label editor is
required for normal printing. Settings > General > Start at Login is optional; check its actual
registration state. Automatic login/logout launch is not yet validated.

LIMITATIONS AND RECOVERY
This is an alpha, not a verified reliable driver. Intermittent BLE stalls,
exact geometry/margins, 4 x 6 physical stock and some lifecycle cases remain
open. The link is released after a job for phone use. A successful software
transmission or empty Print Center queue does not confirm paper output.
Check the bridge's Jobs menu before retrying. Outcome-unknown jobs are not
automatically replayed; inspect the paper, recover the printer buffer and
confirm any duplicate-risk reprint explicitly. Do not repeatedly submit
the same job because output seems delayed.

UNINSTALL WITHOUT A SOURCE CHECKOUT
Review pending jobs and resolve uncertain printer state first. Turn off
Start at Login in Settings > General if enabled. In Settings > Printer,
choose Remove Queue, then Quit from the menu. Move
the installed app to Trash. Private spool/settings remain in:
~/Library/Application Support/MunbynBridge
Use Settings > Advanced > Open Private Application Data to locate it before quitting. Delete
data only after review; ordinary deletion is not secure SSD erasure.
